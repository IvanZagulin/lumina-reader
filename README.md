# Lumina Reader

Современная Android-читалка на Kotlin и Jetpack Compose для EPUB, FB2/FB2.ZIP, PDF и TXT.

## Возможности

### Библиотека

- дизайн в виде книжной полки: обложки стоят на полках, книга открывается с анимацией;
- книжные серии с автоматическими полками и порядком томов;
- главный экран «Непрочитанные»: сначала начатые книги, затем ещё не открытые;
- обычные пользовательские полки, избранное и статусы чтения;
- OPDS-каталоги: добавление, редактирование и удаление своих каталогов, поиск и загрузка книг прямо в библиотеку;
- уведомления о загрузке книг: прогресс, успешное завершение с переходом к книге и понятные ошибки.

### Чтение

- точная пагинация по реальному размеру экрана и настройкам текста;
- обновлённая типографика: настраиваемые шрифты, межстрочный интервал, отступы, выравнивание и переносы;
- анимации перелистывания страниц, плавное прерываемое листание тапами, свайпами и кнопками громкости;
- прогресс по всей книге внизу страницы: тап переключает процент и номер страницы книги, долгое нажатие открывает переход к странице или проценту;
- иллюстрации и обложки EPUB/FB2;
- сноски: открываются во всплывающем окне без потери места в книге;
- выделения и заметки: цветные маркеры, комментарии к цитатам и список всех заметок книги;
- выделение текста снимается обычным тапом, без листания страницы;
- чтение вслух (TTS) в фоне: воспроизведение продолжается при выключенном экране, управление из уведомления;
- темы OLED, тёмная, сепия, бумага и светлая.

### Статистика и мотивация

- расширенная статистика: активность 7/30/365 дней, годовой heatmap, цели, рекорды, читательский профиль, Wrapped, регулярность, анализ сессий, авторов, серий, форматов, бэклога и прогнозов;
- достижения с редкостью, бронзой/серебром/золотом/платиной, секретными медалями, XP и уровнями читателя;
- ежедневное напоминание о чтении: его можно отключить или выбрать удобное время.

### Обновления и данные

- проверка, загрузка и установка обновлений из GitHub Releases с проверкой SHA-256 и подписи APK;
- резервное копирование Android сохраняет базу данных, прогресс и настройки (сами файлы книг в копию не входят).

Новая аналитика строится локально по истории чтения и не требует отдельного сервера.

## Сборка

Требуются Android SDK 35 и JDK 21.

```bash
./gradlew testDebugUnitTest assembleRelease
```

Release APK появляется в `app/build/outputs/apk/release/`.

## Автообновления

Каждый push в `main` (кроме изменений только в документации) запускает тесты, собирает подписанный release APK и публикует новый GitHub Release вместе с файлом контрольной суммы `.sha256`. Приложение выбирает самую новую стабильную версию (черновики и pre-release пропускаются), скачивает APK, сверяет SHA-256 и сертификат подписи с установленным приложением и только после этого предлагает установку.

Для сохранения одной подписи между сборками workflow использует секрет репозитория `ANDROID_DEBUG_KEYSTORE_BASE64`. Закрытые токены и keystore-файлы в репозиторий не добавляются.

На Android 8+ при первой установке обновления потребуется разрешить Lumina устанавливать APK из этого источника. Если вы вернулись из настроек, а установка не началась, нажмите «Открыть настройки» в окне обновления ещё раз.
