# Lumina Reader

Современная Android-читалка на Kotlin и Jetpack Compose для EPUB, FB2/FB2.ZIP, PDF и TXT.

## Возможности

- точная пагинация по реальному размеру экрана и настройкам текста;
- плавное прерываемое перелистывание тапами, свайпами и кнопками громкости;
- счётчик страниц текущей главы и переход к нужному номеру;
- иллюстрации и обложки EPUB/FB2;
- книжные серии с автоматическими полками и порядком томов;
- обычные пользовательские полки, избранное и статусы чтения;
- статистика за день, неделю и всё время, стрики, темп и история сессий;
- темы OLED, тёмная, сепия, бумага и светлая;
- проверка, загрузка и установка обновлений из GitHub Releases.

## Сборка

Требуются Android SDK 35 и JDK 21.

```bash
./gradlew testDebugUnitTest assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Автообновления

Каждый push в `main` запускает тесты, собирает подписанный APK и публикует новый GitHub Release. Приложение проверяет последний публичный релиз через GitHub API и предлагает установить APK.

Для сохранения одной подписи между сборками workflow использует секрет репозитория `ANDROID_DEBUG_KEYSTORE_BASE64`. Закрытые токены и keystore-файлы в репозиторий не добавляются.

На Android 8+ при первой установке обновления потребуется разрешить Lumina устанавливать APK из этого источника.
